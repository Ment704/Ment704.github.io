Virtual Piano — Софт

Инструменты на тему Virtual Piano

VPHub

Комбайнер для создания VP-нот. Аудио в MIDI-файл с помощью Transkun, локальный конвертер MIDI в VP-Ноты, Транспонирование (Transposer) и Упрощатель (Simplifier) нот.

Python GUI

Transposer

Транспонирование VP-нот. Мгновенно меняет тональность любой мелодии, сохраняя структуру и ритм.

Python Music

Simplifier

Облегчает сложные VP-ноты для новичков, упрощая аккорды.

Python Algorithm

VP Sheet Reader

Читалка Trello с VP-нотами. Поддерживает текст и изображения, работает офлайн. Удобный просмотрщик нот.

React Tauri Typescript Trello API
